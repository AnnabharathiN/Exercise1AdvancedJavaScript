# JavaScript Fundamentals — Exercises

A collection of JavaScript exercises completed as part of the 
Full Stack MERN Developer Bootcamp at Matrix Master, Rotterdam.

## Topics Covered

- Objects — creating, reading, updating and deleting properties
- Variables — let, const and scope
- Functions — declaration and scope
- Conditional operators — if/else and ternary operators
- Loops — iterating over objects
- Template literals

## Technologies Used

- JavaScript (ES6+)
